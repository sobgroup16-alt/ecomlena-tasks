# ECOMLENA · Задачи (сайт для GitHub Pages)

Файлы этой папки кладутся в корень репозитория. Сборка не нужна.

1. github.com → New repository → имя `ecomlena-tasks`, Public → Create.
2. «uploading an existing file» → перетащить все файлы и папки (icons, vendor) → Commit.
3. Settings → Pages → Source: Deploy from a branch → Branch: main, / (root) → Save.
4. Через несколько минут сайт откроется по адресу https://<логин>.github.io/ecomlena-tasks/
